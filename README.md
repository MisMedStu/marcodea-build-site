# موقع ماركوديا بيلد

**منشور الآن على:** <https://mismedstu.github.io/marcodea-build-site/> (عنوان مؤقت، مخفي عن محركات البحث)

موقع تعريفي ثابت لشركة **MARCODEA BUILD** — تصميم معماري 2D ورندر ثلاثي الأبعاد، مصراتة — ليبيا.

مبني بـ **Astro 7** و**TypeScript** و**Tailwind CSS 4**. لا خادم ولا قاعدة بيانات: البناء يُخرج ملفات HTML وصورًا جاهزة، فيفتح الموقع سريعًا على شبكات الجوال.

> **للشركة:** إن كنت تريد فقط إضافة مشروع جديد أو تبديل صورة، اقرأ [COMPANY-GUIDE-AR.md](COMPANY-GUIDE-AR.md) — لا تحتاج أي شيء مما في هذا الملف.

---

## التشغيل محليًا

تحتاج **Node.js 20.3 أو أحدث**. تحقّق بـ `node -v`.

```bash
npm install
```

```bash
npm run dev
```

يفتح الموقع على <http://localhost:4321>. أي تعديل يظهر فورًا بلا إعادة تشغيل.

### بقية الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `npm run build` | يبني نسخة النشر في مجلد `dist/` |
| `npm run preview` | يعرض نسخة النشر كما ستظهر على الإنترنت |
| `npm run check` | يفحص الأنواع والأخطاء — يجب أن يخرج بصفر أخطاء |
| `npm run verify` | فحص وبناء معًا — شغّله قبل كل نشر |
| `npm run lh` | يقيس Lighthouse على الجوال والحاسوب ويحفظ التقارير في `qa/` |
| `npm run og` | يعيد توليد صورة المشاركة `public/og-image.jpg` |

> `npm run lh` يحتاج نسخة بناء حديثة: شغّل `npm run build` قبله.

## بنية المشروع

```
src/
  components/   مكوّنات الواجهة — ملف لكل قسم
  layouts/      BaseLayout.astro — الترويسة ووسوم SEO
  pages/        index.astro — الصفحة الوحيدة حاليًا
  data/         content.ts (كل النصوص) · site.ts (بيانات الشركة)
                icons.ts (الأيقونات) · projects.json (المعرض)
  lib/          projects.ts — مصدر المعرض · local-projects.ts — من المستودع
                cms/ — وصلة كل خدمة مستضافة (اختيارية)
  scripts/      contact-form.ts — تحقّق النموذج وبناء رسالة واتساب
  styles/       global.css — كل التوكنات اللونية والمقاسية
  assets/       صور الهوية · fonts/ الخطوط · projects/ صور المعرض
public/         favicon · og-image · apple-touch-icon
                (robots.txt يُولَّد وقت البناء حسب النطاق)
.pages.yml      إعدادات لوحة التحكم
reference/      الموكب الأصلي ودليل الهوية — مرجع فقط، لا يدخل البناء
```

**قاعدتان تحفظان المشروع نظيفًا:**

1. **لا نص مكتوب داخل مكوّن.** كل جملة عربية في `src/data/content.ts`.
2. **لا لون ولا مقاس مكتوب يدويًا داخل مكوّن.** كلها متغيّرات من `src/styles/global.css`.

## إضافة مشروع إلى المعرض

### الطريقة المعتمدة: لوحة التحكم

المعرض يُدار من **[Pages CMS](https://pagescms.org)** — لوحة مجانية مفتوحة المصدر
تُفتح بتسجيل دخول **GitHub**، بلا حساب جديد وبلا بطاقة.

**المهم:** المحتوى والصور تُحفظ **داخل هذا المستودع** لا عند طرف خارجي.
لو أغلقت اللوحة أبوابها غدًا لا يضيع شيء — الملفات مكانها، وتُبدَّل اللوحة بغيرها.

التجهيز لمرة واحدة:

1. ادخل <https://app.pagescms.org> وسجّل الدخول بـ GitHub.
2. امنح الوصول لمستودع هذا الموقع.
3. تظهر اللوحة جاهزة — الإعدادات كلها في ملف [`.pages.yml`](.pages.yml) في جذر المستودع.

خطوات الاستعمال اليومي للشركة في [COMPANY-GUIDE-AR.md](COMPANY-GUIDE-AR.md).

### ما يحدث خلف الكواليس

اللوحة تكتب في ملفين:

- `src/data/projects.json` — بيانات المشاريع
- `src/assets/projects/` — الصور

الصور تمرّ على **تحسين الصور في Astro** كبقية صور الموقع: AVIF وWebP
بأحجام متعددة، فلا تتأثر سرعة الموقع مهما رفعت الشركة صورًا ثقيلة.

### التحرير اليدوي (بلا لوحة)

`src/data/projects.json` ملف عادي يمكن تعديله مباشرة:

```json
{
  "projects": [
    {
      "title": "فيلا العائلة — الزروق",
      "meta": "فيلا سكنية · 300 م²",
      "dims": "20 × 15 m",
      "image": "/projects/villa.jpg",
      "imageAlt": "واجهة فيلا من دورين بإضاءة المساء"
    }
  ]
}
```

الصورة نفسها توضع في `src/assets/projects/villa.jpg`.
القائمة الفارغة `[]` تعني بطاقات فارغة بنمط المخطط الهندسي — وهذا هو الوضع الحالي.

الترتيب هو ترتيب المشاريع في القائمة، وتظهر الثلاثة الأولى:
الأول في البطاقة الكبيرة والاثنان بعده بجانبه.

## خدمة محتوى مستضافة (اختياري)

الموقع يدعم أيضًا ثلاث خدمات مستضافة إن فضّلتها الشركة لاحقًا،
ولا يحتاج التبديل إلا سطرين في `.env`:

```
PUBLIC_CMS_PROVIDER=storyblok
PUBLIC_STORYBLOK_TOKEN=المفتاح
```

القيم المقبولة: `storyblok` أو `datocms` أو `sanity`.
اتركه فارغًا ليقرأ الموقع من المستودع (الوضع الافتراضي).

أنشئ في الخدمة نوع محتوى اسمه `project` بحقول `title` و`meta` و`dims`
و`image` (مع `alt`) و`order`. تفاصيل كل خدمة:

| الخدمة | خطوات إضافية | المفتاح المطلوب |
|---|---|---|
| **[Storyblok](https://www.storyblok.com)** | ضع القصص داخل مجلد اسمه `projects` | Preview/Public Token |
| **[DatoCMS](https://www.datocms.com)** | يكفي أن يكون معرّف النموذج `project` | Read-only API Token |
| **[Sanity](https://www.sanity.io)** | dataset باسم `production` وعام | Project ID |

> المفاتيح كلها **قراءة فقط** ويصحّ ظهورها في موقع عام.
> لا تضع مفتاح كتابة أو إدارة.

**إن تعطّلت الخدمة لا ينهار شيء:** يُكتب تحذير في سجل البناء، ويكمل البناء،
وتظهر البطاقات الفارغة. جُرِّب هذا فعليًا على الخدمات الثلاث.

## استبدال الخط العربي بـ Montaser Arabic

دليل الهوية ينصّ على **Montaser Arabic**، وهو غير متاح مجانًا، فالموقع يعمل حاليًا بـ **Alexandria**.

عند شراء الترخيص:

1. ضع ملفات الخط في `src/assets/fonts/`.
2. أضف `@font-face` له في `src/styles/global.css`.
3. غيّر **سطرًا واحدًا** في الملف نفسه:

   ```css
   --font-ar: 'Montaser Arabic', 'Alexandria Variable', sans-serif;
   ```

لا شيء آخر يتغيّر في المشروع.

## النشر

### الطريقة المعتمدة: GitHub Pages (تلقائي، بلا حساب جديد)

سير النشر جاهز في [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
كل حفظ في الفرع `main` — ومنه كل حفظ من لوحة التحكم — يفحص الموقع
ويبنيه وينشره خلال دقيقتين تقريبًا.

**شرط واحد:** GitHub Pages مجانية للمستودعات **العامة** فقط. سير النشر
لا يعمل ما دام المستودع خاصًا، ويتفعّل وحده حين يصير عامًا.

التفعيل لمرة واحدة من **Settings → Pages → Source: GitHub Actions**.

### النطاق والفهرسة يُضبطان تلقائيًا

| النشر على | الروابط | محركات البحث |
|---|---|---|
| العنوان المؤقت `…github.io/marcodea-build-site/` | تحت المسار الفرعي | **مخفي** — حتى لا ينافس النطاق الحقيقي |
| النطاق `marcodeabuild.ly` | من الجذر | **مفتوح** مع sitemap |

لربط النطاق: **Settings → Pages → Custom domain** ← `marcodeabuild.ly`،
ثم سجل DNS من نوع CNAME عند مزوّد النطاق يشير إلى `mismedstu.github.io`.
لا يتغيّر شيء في الكود — الروابط والفهرسة تتبعان النطاق وحدهما.

### متغيّرات النشر

تُضبط من **Settings → Secrets and variables → Actions → Variables**:

| المتغيّر | القيمة | إلزامي؟ |
|---|---|---|
| `PUBLIC_WHATSAPP` | `218926243113` | لا — هذه القيمة الافتراضية |
| `PUBLIC_CMS_PROVIDER` | فارغ، أو اسم خدمة مستضافة | لا |

### بديل: Cloudflare Pages

إن فضّلت الشركة إبقاء المستودع خاصًا: اربطه من
**Cloudflare → Workers & Pages → Connect to Git**، بأمر البناء `npm run build`
ومجلد الإخراج `dist`. يلزمه حساب Cloudflare.

> إن بِيع الموقع للشركة: انقل المستودع إلى حسابها من
> **Settings → Transfer ownership** — ينتقل معه سير النشر ولوحة التحكم.

## قبل كل نشر

```bash
npm run verify && npm run build && npm run lh
```

المطلوب: صفر أخطاء، صفر تحذيرات، و**95 فأعلى** في مؤشرات Lighthouse الأربعة.

لقياس الموقع المنشور بدل النسخة المحلية:

```bash
npm run lh -- https://mismedstu.github.io/marcodea-build-site/
```

### آخر قياس — على الموقع المنشور فعلًا

| | الجوال | الحاسوب |
|---|---|---|
| الأداء | 97 | 100 |
| إمكانية الوصول | 100 | 100 |
| أفضل الممارسات | 100 | 100 |
| تهيئة محركات البحث | 66 ← 100 على النطاق | 66 ← 100 على النطاق |

**لماذا 66 في محركات البحث؟** لأن العنوان المؤقت **مخفي عمدًا** عن جوجل،
والتدقيق الوحيد الراسب هو «الصفحة ممنوعة من الفهرسة». عند ربط
`marcodeabuild.ly` يُرفع المنع وحده، وقياس نسخة النطاق يعطي 100.

مؤشرات الجوال على الموقع المنشور: أول رسم **1.2 ث**، أكبر عنصر **1.5 ث**،
زمن الحجب **صفر**، إزاحة التخطيط **صفر**.

> درجة الأداء على جهاز التطوير تتذبذب بين 94 و100 حسب انشغال الجهاز.
> القياس المعتمد هو على الرابط المنشور، أو عبر PageSpeed Insights من جوجل.
